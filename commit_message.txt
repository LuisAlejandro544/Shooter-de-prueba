fix(ci): generacion de gradle wrapper binario y ajuste a JDK 21 para compilacion del APK Debug

- Se resolvio el error durante la ejecucion de 'chmod +x gradlew && ./gradlew assembleDebug' en GitHub Actions.
- Causa del problema:
  * El repositorio no incluia el ejecutable binario de 'gradlew' ni el paquete 'gradle/wrapper/gradle-wrapper.jar', por lo que el comando fallaba al intentar invocar el wrapper.
  * Gradle 9.3.1 y AGP 9.1.1 requieren compatibilidad con Java 21 en lugar de Java 17 en el runner de GitHub Actions.
- Correcciones aplicadas:
  * Se ejecuto la tarea oficial 'gradle wrapper --gradle-version 9.3.1' generando los archivos requeridos: 'gradlew', 'gradlew.bat' y 'gradle/wrapper/gradle-wrapper.jar'.
  * Se actualizo el workflow '.github/workflows/build-debug.yml' para utilizar 'java-version: 21' (Temurin) compatible con Gradle 9.3.1.
  * Se conservo la configuracion sin cache y la ejecucion aislada para la compilacion limpia de C++, Rust y Lua.
